# Raycast

In **Settings → Extensions → Script Commands → Add Script Directory**, add:

- macOS: `$MC_HOME/config/raycast/commands`
- Windows: `%MC_HOME%\config\raycast\commands`

This registration is manual. Add it again if the repo moves.
Commands live in [`commands/`](commands/).

For **Command-Space** hotkey on macOS: disable Spotlight's shortcut under
**System Settings → Keyboard → Keyboard Shortcuts → Spotlight**,
then set the Raycast hotkey.
